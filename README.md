A WordPress plugin for property managers, landlords, and real estate management companies. Provides tenants a self-service portal to submit maintenance requests with photo uploads, track repair status, pay rent online, view lease documents, and message property managers. On the admin side, it routes requests by property and unit, assigns work orders to contractors, tracks repair costs per unit, and generates monthly maintenance summary reports for owner reporting.

== Description ==

A WordPress plugin for property managers, landlords, and real estate management companies. Provides tenants a self-service portal to submit maintenance requests with photo uploads, track repair status, pay rent online, view lease documents, and message property managers. On the admin side, it routes requests by property and unit, assigns work orders to contractors, tracks repair costs per unit, and generates monthly maintenance summary reports for owner reporting.

**Features:**

* Core functionality

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate via WordPress admin > Plugins
3. Configure via Settings > Property Management Maintenance Request and Tenant Portal WordPress Plugin
